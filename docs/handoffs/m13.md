# Nota de entrega — M13 (CRUD SQLite de contactos y alertas)

- **Depende de:** M4, M5 y M12

## Hecho

- CRUD de alertas: listado y consulta por ID de registros activos, guardado
  parametrizado y borrado lógico con estado pendiente de sincronización.
- Repositorio de contactos cubierto directamente por pruebas SQL; el cambio de
  contacto principal ahora es una sola escritura atómica.
- Prueba de migraciones: verifica tablas de dominio y reutilización de la
  instancia SQLite.
- Los repositorios dependen solo de las operaciones SQLite requeridas, lo que
  permite probar el SQL mediante dobles tipados.
